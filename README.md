# Athuliya Asokakumar | Portfolio

A professional portfolio website showcasing operations expertise, professional experience, and academic background.

## 🌐 Live Site
Your portfolio is live at: `https://athuliyaasok.github.io/portfolio/`

## 📋 Features
- **Responsive Design** - Looks great on all devices (mobile, tablet, desktop)
- **Professional Layout** - Clean, minimal aesthetic with sage green color scheme
- **Hero Section** - Eye-catching introduction with badges
- **About & Competencies** - Core skills and expertise overview
- **Experience Timeline** - Professional journey with contributions
- **Academic Foundation** - Education and credentials
- **Contact Section** - Email, phone, and LinkedIn links
- **Resume Download** - One-click PDF download

## 📁 Files
- `index.html` - Main portfolio website
- `resume.pdf` - Your resume (add your PDF file here)
- `README.md` - This file

## 🚀 Setup
1. Upload your `resume.pdf` to the root of this repository
2. The site will automatically be served at `https://athuliyaasok.github.io/portfolio/`
3. No additional build steps required!

## 🎨 Customization
Edit the `index.html` file to update:
- Contact information
- Professional experience
- Academic details
- Links and social profiles
